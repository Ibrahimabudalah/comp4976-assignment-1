Municipal Elections Management System (MEMS)
COMP 4976 - Assignment 1
BCIT - Computer Systems Technology



##PROJECT DESCRIPTION

MEMS is an ASP.NET Core MVC web application
for managing municipal elections.

Administrators can manage municipalities,
positions, and candidates.

Public users can browse candidates, search
and filter results, and create their own
printable voting guides.

Additional features include dark mode,
candidate pagination, and PDF export.
